# GitNexus — Code Intelligence

This project is indexed by GitNexus as **gvtech-design** (3527 symbols, 7677 relationships, 105 execution flows). Use the GitNexus MCP tools to understand code, assess impact, and navigate safely.

> Index stale? Run `node .gitnexus/run.cjs analyze` from the project root — it auto-selects an available runner. No `.gitnexus/run.cjs` yet? `npx gitnexus analyze` (npm 11 crash → `npm i -g gitnexus`; #1939).

## Always Do

- **MUST run impact analysis before editing any symbol.** Before modifying a function, class, or method, run `impact({target: "symbolName", direction: "upstream"})` and report the blast radius (direct callers, affected processes, risk level) to the user.
- **MUST run `detect_changes()` before committing** to verify your changes only affect expected symbols and execution flows. For regression review, compare against the default branch: `detect_changes({scope: "compare", base_ref: "main"})`.
- **MUST warn the user** if impact analysis returns HIGH or CRITICAL risk before proceeding with edits.
- When exploring unfamiliar code, use `query({query: "concept"})` to find execution flows instead of grepping. It returns process-grouped results ranked by relevance.
- When you need full context on a specific symbol — callers, callees, which execution flows it participates in — use `context({name: "symbolName"})`.

## Never Do

- NEVER edit a function, class, or method without first running `impact` on it.
- NEVER ignore HIGH or CRITICAL risk warnings from impact analysis.
- NEVER rename symbols with find-and-replace — use `rename` which understands the call graph.
- NEVER commit changes without running `detect_changes()` to check affected scope.

# GVTech Design System — agent notes

Docs entry: `docs/index.md` (Diataxis). Ignore `.github/copilot-instructions.md` — it describes a retired single-package `src/components/ui` layout; trust `packages/*/src`.

## Commands (bun only, never npm/yarn)

- Install: `bun install` (CI uses `--frozen-lockfile`). Toolchain: bun 1.3.x, node 24 (`.tool-versions`; CI matrix 22+24).
- Dev: `bun run dev` (playground-web) · native: `bun run native` / `native:android` / `native:clear`.
- Order matters: `bun run sync-tokens` → `bun run build:registry` → `bun run generate:contract-tests` → `bun run validate` (`validate:fix` to repair).
- Focused: `bun run lint`, single test `bunx vitest run <path-to-test>`, package scope `bun --filter <pkg> <script>` or `bunx nx run-many -t <target>`.
- CI runs `format:ci` → `lint` → `test:ci`, then `build` + `build:site`. Pre-commit runs lint-staged (prettier + `eslint --fix`).

## Architecture (contract-first Nx monorepo)

- `packages/ui-core/src/contracts/` is the API source of truth. `ui-web` and `ui-native` import types from `@gv-tech/ui-core` — never redefine props/variants/sizes per platform.
- `packages/design-tokens/src/` (palette, theme, spacing, typography, shadows) is the token source. `theme.css` and Flutter `gv_tokens.g.dart` are generated by `sync-tokens` — never hand-edit, no per-platform forks.
- `ui-web` = Radix + Tailwind v4 (import tokens CSS **before** `tailwindcss`). `ui-native` = RN Reusables + NativeWind v5 + Reanimated, Expo CNG (`apps/native-playground`, no `/ios` or `/android` dirs).
- New components: `bun run generate:component <Name> [--category]` scaffolds contract + both impls + playground tabs (`apps/playground-web` routes in `src/routes/doc-routes.tsx`, nav in `src/config/docs.ts`).
- After component changes: rerun `build:registry` (emits shadcn JSON to `packages/*/registry.json` + `public/registry`) and update `docs/reference/component-registry.md`, `parity-matrix.md`, `divergence-registry.md` together.

## Gotchas

- Native tests run in Vitest/jsdom via a `react-native-web` shim (vitest aliases `react-native` to the playground shim) — no device needed. Typical failure: web-only props (`onClick`, `htmlFor`, `onChange`) leaked into a native impl. Mappings: `onClick→onPress`, `onChange→onChangeText`, `htmlFor→nativeID`, CSS animation→Reanimated.
- Intentionally web-only components stay unimplemented on native (Chart/recharts, Command/cmdk, Resizable, Scroll Area, Sonner) — use native equivalents (Toast, ScrollView, Sheet) and note it in the parity matrix.
- `lightningcss: 1.30.1` in `overrides` + `resolutions` is required by NativeWind v5 — do not remove.
- Releases use Nx Release lock-step (`v{version}` tags), Sundays + manual dispatch, OIDC publish. Conventional Commits are required (they drive version bumps and changelogs); archived release-please notes are retired.
