# How-to: Use Tokens with Tailwind v4

Task: wire `@gv-tech/design-tokens` into a web app with light/dark support.

## Steps

1. Install: `bun add @gv-tech/design-tokens`
2. In your global CSS, import tokens **before** Tailwind:

```css
/* src/globals.css */
@import '@gv-tech/design-tokens/theme.css';
@import 'tailwindcss';
```

3. Use semantic classes (`bg-background`, `text-foreground`, `bg-primary`, …). Variables come from `packages/design-tokens/src/theme.ts` + `palette.ts`, generated by `scripts/sync-tokens.ts` into `theme.css`.
4. Dark mode: toggle `.dark` on `<html>` (the `ThemeProvider` / `Theme Toggle` component does this). Tokens under `.dark` in `theme.css` take over automatically.

## Regenerate after token edits

```bash
bun run sync-tokens
# → rewrites packages/design-tokens/src/theme.css (+ Flutter gv_tokens.g.dart)
```

Never hand-edit `theme.css` — edit `palette.ts` / `theme.ts` then re-run. See [Tokens Reference](../reference/tokens.md).
